# Geographic Information Systems: Foundations

A Geographic Information System (GIS) is a system for capturing, storing, managing, analyzing, and visualizing data linked to locations on Earth. GIS commonly represents real-world features as vector data—points, lines, and polygons—or as raster data made from a grid of cells.

Vector data is well suited to discrete objects. A well can be a point, a road a line, and a district boundary a polygon. Raster data is well suited to continuous phenomena such as elevation, temperature, or satellite reflectance. Each raster cell stores a value for a fixed area.

Every GIS layer uses a coordinate reference system (CRS). A geographic CRS describes positions with angular coordinates such as latitude and longitude. A projected CRS transforms the curved Earth onto a flat surface and uses linear units, which makes local distance and area calculations more practical. Layers should be transformed to compatible coordinate systems before spatial analysis.

Common GIS operations include buffering features by a distance, overlaying layers, finding objects contained by an area, calculating shortest paths on a network, and interpolating values between sampled locations. GIS is applied in urban planning, disaster response, public health, transportation, agriculture, utilities, and environmental monitoring.
